Privacy Policy

Effective: November 13, 2026

1. Overview

Julian Clips Pipeline is a personal desktop application for creating and publishing short-form podcast clips. This policy describes how data is handled.

2. Data Collection

This application does not collect, store, or process personal data from end users. It is not a consumer-facing service. The only data handled is:

  • Video files created and edited locally on the operator's machine
  • API authentication tokens stored locally for publishing to social media platforms
  • Metadata (titles, descriptions, hashtags) generated for published content

3. Third-Party Services

This application connects to the following platforms via their official APIs:

  • TikTok — Content Posting API for video uploads
  • YouTube — Data API v3 for Shorts uploads
  • Instagram — Graph API for Reels uploads

Each platform's own privacy policy governs data once published there.

4. Data Storage

All data is stored locally on the operator's computer. No data is transmitted to any server other than the social media platforms listed above for the sole purpose of publishing content.

5. Data Sharing

No personal data is shared with third parties. Published video content is shared publicly on social media platforms as intended by the operator.

6. Security

API credentials are stored in a local configuration file on the operator's machine and are not transmitted or shared.

7. Changes

This privacy policy may be updated at any time. Changes take effect immediately upon posting.

8. Contact

For privacy-related inquiries, reach out via the Julian Dorey Podcast community channels.
